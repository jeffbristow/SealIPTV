First release on GitHub, for Windows and Fire TV.

- Updates: Seal IPTV now looks for a new version when it starts and installs it with one click — no new installer on Windows, and usually no new APK on Fire TV.
- Posters: missing or broken posters are filled in by title — series from TVmaze, movies and series from TMDB with a free API key (Settings → Posters).
- Fire TV: typing works in every form field (OK opens a text box with the keyboard), and the screens fit the TV.

Install 1.1.0 once by hand (Windows installer, Fire TV APK); later versions arrive through Update.
