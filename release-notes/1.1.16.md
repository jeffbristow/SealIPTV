- TV: the parental PIN is typed on a number pad beside the PIN box, with the remote's arrows and OK, or with the remote's own 0–9 keys if it has them. No keyboard pops up. After a wrong PIN, the next digits start the PIN again.
- Buttons that delete or clear something now ask with Cancel selected first and a red button to go ahead, so pressing OK twice can't delete anything by mistake. This covers deleting a playlist or a category, clearing watch history, removing the PIN, and disconnecting or deleting the sync vault.
- Delete buttons sit a little apart from the buttons next to them.

On the TV, Settings → About → Check for updates installs it. Windows updates by itself.
